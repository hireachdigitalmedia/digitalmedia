# Site images

All photos in `home-image/`, `iptv-image/`, `ott-image/` and `partners-image/` come from the
**Hi Reach Digital Media design files supplied by the client** (cropped from the page designs).
Confirm commercial-use rights for these images with the design owner before launch.

Every image is processed the same way so they read as one set: slight darken (95 %),
slight desaturate (94 %), soft edge vignette, WebP quality 80. A CSS grade (bottom fade +
inner highlight) is added on top by `components/MediaFrame` and the card components.

| File                                | Used for                           |
| ----------------------------------- | ---------------------------------- |
| `home-image/hero-living-room.webp`  | Home & Entertainment hero          |
| `home-image/movies.webp`            | Movies cards / tiles               |
| `home-image/web-series.webp`        | Web Series cards / tiles           |
| `home-image/regional.webp`          | Regional cards / tiles             |
| `home-image/sports.webp`            | Sports cards / tiles               |
| `home-image/family.webp`            | Family cards / tiles               |
| `iptv-image/residential.webp`       | IPTV "Residential Viewing"         |
| `ott-image/ott-hero.webp`           | OTT hero                           |
| `ott-image/live-entertainment.webp` | OTT "Live Entertainment" card      |
| `partners-image/partners-hero.webp` | Distribution Partners & About hero |

Live TV visuals (IPTV hero, Home IPTV section, Live TV cards) are **not photos**: they are the
coded `TvGuideMockup` component with fictional channel names, to avoid showing real broadcaster
or streaming-app trademarks.
